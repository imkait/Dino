# 道具系統 walkthrough

## 背景
本次任務為 Dino 跑酷遊戲加入可拾取道具，讓玩家在原本的奔跑與跳躍體驗之上，額外獲得策略選擇與遊戲節奏變化。

## 變更內容
- 新增 `powerups` 陣列，用來追蹤道具位置與狀態。
- 以固定時間間隔隨機生成 `shield` 與 `double` 兩種道具。
- 擴展碰撞判定，讓玩家碰到道具後立即觸發效果。
- 在畫面上加入道具繪製與護盾環狀效果，強化互動回饋。
- 護盾效果可暫時防止一次障礙碰撞，雙倍分數會提高分數發展速度。

- 視實際遊戲體驗調整道具出現頻率與持續時間。
